# Interview - 계획 파일 기반 인터뷰 스킬

계획(plan) 파일을 읽고 사용자에게 구현 관련 심층 질문을 수행하는 스킬입니다.

## 사용 시점
- `/interview` 명령 시
- "인터뷰 시작", "plan 인터뷰" 등 요청 시
- 계획 파일 작성 후 구체화가 필요할 때

## 실행 방법

1. **계획 파일 찾기**: ~/.claude/plans/ 디렉토리에서 최신 plan 파일을 찾습니다
2. **계획 파일 읽기**: 해당 파일을 읽고 내용을 분석합니다
3. **심층 질문 수행**: AskUserQuestion 도구를 사용하여 다음 영역에 대해 질문합니다:
   - 기술 구현 (Technical Implementation)
   - UI/UX 결정사항
   - 우려사항 및 리스크
   - 트레이드오프 및 대안

## 질문 규칙

- 뻔한 질문은 하지 않습니다
- 심층적이고 구체적인 질문을 합니다
- 완료될 때까지 계속 질문합니다
- 모든 질문이 끝나면 spec 문서를 작성합니다

## 출력
인터뷰 완료 후 상세 spec 문서 작성
