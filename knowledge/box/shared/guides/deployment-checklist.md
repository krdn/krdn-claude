# 배포 체크리스트

## 배포 전 확인사항

### 1. 코드 품질
- [ ] 모든 테스트 통과
- [ ] 린트 에러 없음
- [ ] 빌드 성공

### 2. Git 상태
- [ ] 모든 변경사항 커밋됨
- [ ] 올바른 브랜치 (main/master)
- [ ] 원격과 동기화됨

### 3. 환경 설정
- [ ] 환경 변수 설정 확인
- [ ] 시크릿 키 확인
- [ ] 데이터베이스 마이그레이션 준비

### 4. 시스템 리소스
- [ ] 디스크 공간 충분
- [ ] 메모리 여유 있음
- [ ] 서비스 상태 정상

## 배포 후 확인사항

### 1. 헬스체크
- [ ] 서비스 응답 확인
- [ ] 헬스체크 엔드포인트 정상

### 2. 기능 검증
- [ ] 주요 기능 동작 확인
- [ ] 에러 로그 확인

### 3. 모니터링
- [ ] 리소스 사용량 정상
- [ ] 응답 시간 정상

## 롤백 조건

다음 상황 발생 시 즉시 롤백:
- 헬스체크 3회 연속 실패
- 에러율 급증 (배포 전 대비 500% 이상)
- 주요 기능 장애

## 롤백 명령어

```bash
# 일반
/deploy rollback [project]

# 스크립트 직접 실행
~/.claude/skills/deploy-manager/scripts/rollback.sh [project]
```
